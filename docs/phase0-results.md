# Phase 0 실측 결과

> `docs/phase0-checklist.md` 항목별 기록. 1차 방문: 2026-10-18.

## A. 환경
| 항목 | 결과 |
|---|---|
| A1 마우스 DPI 확인 수단 | **소프트웨어**(로지텍 G HUB). 마우스 = 로지텍 G102 LIGHTSYNC. DPI 800, 보고율 1000 확인. 기존 DPI 단계 400/800/1600/3200 중 **800만 남기고 삭제**(DPI 버튼 오작동 방지) |
| A2 Windows 포인터 설정 | **변경 가능(잠김 아님).** 포인터 속도 6/11 정상. "포인터 정확도 향상"이 켜져 있었음 → 해제·적용됨 |
| A3 폰 네트워크 | 데이터 사용 가능 |

### 설계 반영 메모
- 0-B 2번(마우스 확인)에 **G102 체크 항목** 추가 후보: G HUB에서 DPI 단계가 800 하나뿐인지, 보고율 1000인지, 게임 전용 프로필이 있으면 그쪽도 같은지.
- 0-B 1번(Windows)은 이 PC방에서 "변경 가능". 정확도 향상이 기본으로 켜져 있었으므로 **매 방문 확인 필요**.
- 미확인: G HUB 게임 전용 프로필(배틀그라운드) 존재 여부.

## B. 설정 메뉴
경로: **설정 → 컨트롤 → 감도 탭 → 마우스**. 스크린샷 1장(1차 방문).

| 순서 | 인게임 이름 | 화면 값 | 기획서 용어 |
|---|---|---|---|
| 1 | 마우스 반전 | 비활성화 | (해당 없음) |
| 2 | 일반 상태 감도 | 30 | 일반 |
| 3 | 수직 감도 배수 | 1.15 | 수직 배율 (소수 둘째 자리 표시 → 단위 0.01 추정) |
| 4 | 조준 감도 | 30 | 조준 |
| 5 | 스코프 모드 감도 | 30 | 조준경 (레드닷·홀로·아이언은 별도 항목 없음 → 묶음 가정 확인) |
| 6 | 통합 스코프 감도 | 비활성화 | **통일 토글 — 존재 확인(B2)** |
| 7 | 2배율 스코프 감도 | 28 | 2x |
| 8 | 3배율 스코프 감도 | 25 | 3x |
| 9 | 4배율 스코프 감도 | 23 | 4x |
| 10 | 6배율 스코프 감도 | 20 | 6x |
| 11 | 8배율 스코프 감도 | 18 | 8x |
| 12 | 15배율 스코프 감도 | 15 | 15x |

- 1인칭/3인칭 별도 감도, 카메라 감도, 차량 감도 항목은 이 화면에 없음.
- 마우스 가속·스무딩 옵션은 이 화면에 없음(B5 잠정: 없음).
- 위 순서가 **복원 카드 순서**가 된다.
- 15배율 아래 항목 없음(전체 12항목 확정).
- **위 값은 사용자 본인의 평소 감도** → 시작값 `S = 30`. 배율은 본인이 일반 대비 Δ −2/−5/−7/−10/−12/−15로 점점 낮춰 쓰는 분리형(프리셋 A보다 고배율을 더 낮춤).
- **B2 통합 스코프 감도 ON**: 2~15배율 값이 모두 스코프 모드 감도 값(30)으로 통일됨. 즉 통일 기준은 "일반"이 아니라 **스코프 모드 감도**.
- **B3** 숫자 키보드 입력 가능. 소수 입력 여부 미확인.
- **B4** 수직 감도 배수 범위 **0 ~ 2**, 표시 소수 둘째 자리.

### 설계 반영 메모
- Step 4 통일 모드 = 토글 ON + 스코프 모드 감도 하나만 정하면 됨(배율 6개 입력 불필요).
- Step 4 분리 모드에 **"내 현재 배율 간격 유지"** 옵션 추가 후보: 일반이 바뀌면 현재 Δ(−2…−15)를 그대로 따라감. 프리셋 A보다 사용자 습관에 가까움.
- 스키마 수직 배율 범위 0~2.
